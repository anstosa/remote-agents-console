# Documentation screenshots

## Operator-supplied workspace

[`console-workspace.png`](console-workspace.png) is the operator-supplied image
used in the technical white paper. It shows agent, terminal, notes, and embedded
project-preview panels in a running workspace. It is not generated by the capture
script and is not a synthetic fixture or a performance benchmark.

## Generated demonstrations

`console-overview.png`, `queued-prompts.png`, `worktree-notes.png`, and
`mobile-console.png` are generated from the browser application with synthetic
agents, paths, prompts, Git state, and terminal output. These generated images
contain no live worktree or operator data.

Regenerate the demonstration images from the repository root:

```bash
pnpm --filter @rac/web screenshots:readme
```

The capture script starts a temporary Vite server on `127.0.0.1:4174`, mocks
the API and WebSocket boundaries in Playwright, writes the four demonstration
PNGs in this directory, and shuts the server down when complete. It leaves
`console-workspace.png` untouched.
